A command-line tool for your Mac. Plug in your iPhone with a cable. It reads your apps, sorts them into groups with a model that runs on your Mac, and shows you tidier layouts. Nothing on the phone changes until you say so.

Meet the crew

The tool works in steps. Each step saves its result in a folder on your Mac, so you can run any step again on its own. Here is who does what.

  1. Step 1 · scan

    Scoot

    Reads the list of apps and your current Home Screen over the cable, using Apple Configurator's cfgutil. Saves a backup right away.

  2. Step 2 · enrich

    Pagelet

    Looks up each app's App Store genre and description. This is the only step that goes online, and you can skip it with --offline.

  3. Step 3 · classify

    Sortle

    Puts each app in a group, like Money or Media. Simple rules handle the obvious ones. A model on your Mac (Ollama or Apple's own) decides the rest.

  4. Step 4 · plan

    Gridley

    Builds the new layouts and checks each one against iOS limits: 24 icons a page, 4 in the dock, 9 per folder page, 15 pages.

  5. Step 5 · preview

    Lumi

    Writes a web page that shows each proposal next to your current layout, so you can compare before anything changes.

  6. Only if you ask · apply · restore

    Rewindle

    Backs up the phone, shows how much will move, and asks you first. Then writes the layout you picked. Changed your mind? restore puts the old one back.

Every layout keeps the dock as it is and puts every icon on the screen exactly once. Tap a folder to open it. Swipe or use the arrows to change pages.

Safe by design

  • Only apply and restore write to the phone, and both ask you first.
  • Every scan and every apply saves your layout to ~/.organize-my-iphone/backups/.
  • A layout is refused if it would drop an icon, show one twice, or break an iOS limit.
  • The dock is never rearranged.
  • Web clips and anything the tool doesn't recognize are kept, not thrown away.
  • Try apply --dry-run first to see exactly what would move.

Private by default

  • Your list of apps stays on your Mac, in ~/.organize-my-iphone.
  • The sorting model runs on your Mac. No cloud model is called.
  • The one network call sends app IDs (like com.example.notes) to Apple's App Store lookup, and nothing else.
  • --offline skips that call completely.

Get started

You need

  • A Mac with macOS 15 or later
  • Xcode 26 or later, to build
  • Apple Configurator, which includes cfgutil
  • An iPhone on a cable, unlocked, that trusts this Mac
  • Optional: Ollama, or macOS 26 with Apple Intelligence on

Quit the Apple Configurator app before you scan. While it's open, it holds on to the phone.

Run it

# Get the code
git clone https://github.com/pacphi/organize-my-iphone.git
cd organize-my-iphone

# 1. Check your setup
swift run organize-my-iphone doctor

# 2. Scan, sort, plan and preview. Changes nothing.
swift run organize-my-iphone run --open

# 3. See what would move, then apply the one you like
swift run organize-my-iphone apply folder-board --dry-run
swift run organize-my-iphone apply folder-board

# Changed your mind?
swift run organize-my-iphone restore

No iPhone handy? make demo runs the whole thing against a pretend one.

Honest status

Version 0.1.0 is a first cut. The logic has unit tests, and every change runs the whole pipeline against a pretend iPhone. It has been run from scan to restore on one real iPhone so far. Writing a layout relies on cfgutil, which behaves differently on different iOS versions, so use --dry-run first and keep your backups.
