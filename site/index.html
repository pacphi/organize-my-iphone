Your Home Screen
is a junk drawer.
Let's fix that.

organize-my-iphone is a command-line tool for your Mac. Plug in your iPhone, and a small crew of critters reads your apps, sorts them into groups with a model that runs on your Mac, and lays out twelve tidier Home Screens for you to try. Nothing on the phone moves until you say so. Pinky promise. Backed up, too.

Why does this exist?

A short comic in four panels. Spoiler: it has a happy ending.

  1. 1
    GULP!

    Apps pile up

    Every new app lands in the next empty spot. A few years later you have page after page in the order you happened to install things, plus a folder called "Stuff 2".

  2. 2
    Where is it…
    SWIPE…

    Finding things is a hunt

    You swipe through pages looking for that one app, give up, and type its name into search. Again. Your thumb deserves better.

  3. 3
    WOBBLE…

    Tidying by hand is a chore

    The iPhone has no "sort my Home Screen" button. Tidying means wiggly icons and dragging them one at a time, across pages, for a long, long time.

  4. 4
    TA-DA!

    So the crew does it for you

    One command on your Mac sorts every app at once and shows you the results first. You pick the one you like. If you regret it, one more command puts everything back.

What you get: apps grouped the way you think, found in fewer swipes. What it costs: a cable and a couple of minutes. What it risks: very little, because it saves a backup before every change and won't write anything without asking.

Meet the crew

The tool works in steps. Each step saves its result in a folder on your Mac, so you can run any step again on its own. Here is who does what.

  1. Step 1 · scan

    Scoot

    Reads the list of apps and your current Home Screen over the cable, using Apple Configurator's cfgutil. Saves a backup right away.

  2. Step 2 · enrich

    Pagelet

    Looks up each app's App Store genre and description. This is the only step that goes online, and you can skip it with --offline.

  3. Step 3 · classify

    Sortle

    Puts each app in a group, like Money or Media. Simple rules handle the obvious ones. A model on your Mac (Ollama or Apple's own) decides the rest.

  4. Step 4 · plan

    Gridley

    Builds all twelve layouts and checks each one against iOS limits: 24 icons a page, 4 in the dock, 9 per folder page, 15 pages.

  5. Step 5 · preview

    Lumi

    Writes a web page that shows each proposal next to your current layout, so you can compare before anything changes.

  6. Only if you ask · apply · restore

    Rewindle

    Backs up the phone, shows how much will move, and asks you first. Then writes the layout you picked. Changed your mind? restore puts the old one back.

A tour of the commands

Scroll slowly. The terminal follows along. (It's example output, shortened. The apps are made up.)

Terminal

          

          
        

        
    
          
  1. 
            
    doctor · reads only
    
            
    "Is everybody here?"
    
            
    Checks for Apple Configurator's cfgutil, a connected and trusting iPhone, and a local model. Run it first. It changes nothing, it just takes attendance.
    
          
    2. 
          
  2. 
            
    run · reads only
    
            
    The whole show in one go
    
            
    Runs scan, enrich, classify, plan and preview back to back, then opens the preview page with --open. This is the one most people need. Add --offline to skip the App Store lookup.
    
          
    3. 
          
  3. 
            
    scan · reads only
    
            
    Scoot takes a census
    
            
    Reads every app and your current layout, and saves a backup of that layout straight away. Belt, meet braces.
    
          
    4. 
          
  4. 
            
    enrich · no phone needed
    
            
    Pagelet does the reading
    
            
    Looks up each app's App Store genre and description, so the sorting has more to go on. It sends Apple only the app IDs. Skip it with --offline.
    
            
    New: add --icon-colors-from-store and it also fetches each app's icon to find its color for the Rainbow layout. See the color wheel.
    
          
    5. 
          
  5. 
            
    classify · no phone needed
    
            
    Sortle files everything
    
            
    Rules handle the sure things. A model on your Mac (Ollama, or Apple's on-device model) decides the rest. No model? Rules do it all. Want your own groups? Pass a --taxonomy file.
    
          
    6. 
          
  6. 
            
    plan · no phone needed
    
            
    Gridley draws the floor plans
    
            
    Builds each layout and checks it against the iOS limits. A plan that would drop an icon, show one twice, or overflow a page is refused, not "fixed later".
    
          
    7. 
          
  7. 
            
    preview · no phone needed
    
            
    Lumi lights up the options
    
            
    Writes a web page with each proposal next to your current layout. Look, compare, change your mind as often as you like. It's free to window-shop.
    
          
    8. 
          
  8. 
            
    apply --dry-run · reads only
    
            
    The rehearsal
    
            
    Shows exactly how many icons would move, without writing anything. Always rehearse first.
    
          
    9. 
          
  9. 
            
    apply · writes
    
            
    The big moment
    
            
    Rereads the phone, checks the plan still fits, shows the size of the change, saves a backup, and asks you to confirm. Only then does it write.
    
          
    10. 
          
  10. 
            
    restore · writes
    
            
    Rewindle's favorite trick
    
            
    Puts a backed-up layout back, after asking. Regret has never been so cheap.

Rainbelle's color wheel new

      
The Rainbow layout needs to know what color each icon is. Your phone won't say, so Rainbelle finds out another way, and you get the final word.

      

        

          
          
    
            
  1. Built in: Apple's own apps already have colors in a table inside the tool.
    2. 
            
  2. From the App Store: add --icon-colors-from-store to enrich or run. It downloads each app's icon from Apple's image server, shrinks it in memory, and finds its main color. This is opt-in and skipped with --offline.
    3. 
            
  3. Your fixes: preview also writes colors.html, a wheel like this one. Click the right slice for any app that landed in the wrong one, save, and pass the file with --icon-colors. Your file always wins.
    4. 
          

        

        

          
          

            

            

            
    
          
    
        
    
      
    
    
    

    
    
    
      
    
        
        
    Safe by design
    
        
      
          
    • Only apply and restore write to the phone, and both ask you first.
      • 
          
    • Every scan and every apply saves your layout to ~/.organize-my-iphone/backups/.
      • 
          
    • A layout is refused if it would drop an icon, show one twice, or break an iOS limit.
      • 
          
    • The dock is never rearranged.
      • 
          
    • Web clips and anything the tool doesn't recognize are kept, not thrown away.
      • 
          
    • Try apply --dry-run first to see exactly what would move.
      • 
        
    
      
    
      
    
        
        
    Private by default
    
        
      
          
    • Your list of apps stays on your Mac, in ~/.organize-my-iphone.
      • 
          
    • The sorting model runs on your Mac. No cloud model is called.
      • 
          
    • The App Store lookup sends app IDs (like com.example.notes) to Apple, and nothing else.
      • 
          
    • Only if you add --icon-colors-from-store, it also downloads app icons from Apple's image servers to find their colors. They're looked at in memory and not kept.
      • 
          
    • --offline skips both.
      • 
          
    • Your --usage, --recent and --icon-colors files are read on your Mac and never sent anywhere.
      • 
        
    
      
    
    
    

    
    
    
      
    Get started
    
      
    
        
    
          
    You need
    
          
      
            
    • A Mac with macOS 15 or later
      • 
            
    • Xcode 26 or later, to build
      • 
            
    • Apple Configurator, which includes cfgutil
      • 
            
    • An iPhone on a cable, unlocked, that trusts this Mac
      • 
            
    • Optional: Ollama, or macOS 26 with Apple Intelligence on
      • 
          
    
          
    Quit the Apple Configurator app before you scan. While it's open, it holds on to the phone.
    
        
    
        
    
          
    Run it
    

    # Get the code
git clone https://github.com/pacphi/organize-my-iphone.git
cd organize-my-iphone

# 1. Check your setup
swift run organize-my-iphone doctor

# 2. Scan, sort, plan and preview. Changes nothing.
swift run organize-my-iphone run --open

# 3. See what would move, then apply the one you like
swift run organize-my-iphone apply folder-board --dry-run
swift run organize-my-iphone apply folder-board

# Changed your mind?
swift run organize-my-iphone restore
    
          
    No iPhone handy? make demo runs the whole thing against a pretend one.
    
        
    
      
    
    
    

    
    
      
      
    
        
    Honest status
    
        
    Version 0.1.0 is a first cut. The logic has unit tests, and every change runs the whole pipeline against a pretend iPhone. It has been run from scan to restore on one real iPhone so far. The ten newer layouts have so far been applied only to the pretend iPhone, though each passes the same checks before apply will write it. Writing a layout relies on cfgutil, which behaves differently on different iOS versions, so use --dry-run first and keep your backups.
